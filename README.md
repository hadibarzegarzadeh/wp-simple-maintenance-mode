# Simple Maintenance Mode

A tiny WordPress plugin that shows a maintenance page (HTTP 503) to visitors while administrators keep full access.

## Features
- One-click enable from Settings > Maintenance Mode
- Custom maintenance message
- Admins (manage_options) always see the real site

## Installation
1. Copy `simple-maintenance-mode.php` into `wp-content/plugins/simple-maintenance-mode/`
2. Activate the plugin
3. Go to Settings > Maintenance Mode and enable it
